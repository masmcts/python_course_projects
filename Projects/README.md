# 2-Week Python Course Projects

Two capstone projects at the end of each week, built from your 18-topic syllabus.

## Week 1 (Topics 01–09: Intro → Functions)
| Project | Folder | Covers |
|---|---|---|
| Contact Book CLI | `week1/project1_contact_book/` | lists, dicts, strings, loops, conditionals, functions |
| Quiz Game Engine | `week1/project2_quiz_game/` | lists of dicts, loops, conditionals, functions |

## Week 2 (Topics 10–18: Scope → *args/**kwargs)
| Project | Folder | Covers |
|---|---|---|
| Bank Account Manager | `week2/project3_bank_manager/` | OOP, classes, methods, exceptions, file I/O, modules |
| Inventory Manager | `week2/project4_inventory_manager/` | OOP, *args/**kwargs, exceptions, file I/O (CSV), scope |

## How to use each folder
- `TUTORIAL.md` — hand this to students. It has the goal, requirements,
  a step-by-step build guide, stretch goals, and a testing checklist.
  It does **not** contain the answer.
- `solution.py` (or `solution/` folder for Project 3, which is split into
  modules to practice imports) — the full working reference solution,
  for instructors or for students to check their work after attempting it.

## Suggested pacing
- **Days 1–4 (Week 1):** work through topics 01–09, using the existing
  per-topic files from the original course zip as daily exercises.
- **Day 5 (Week 1):** students build Project 1 and/or Project 2 as a
  checkpoint, using only what's been taught so far.
- **Days 1–4 (Week 2):** work through topics 10–18.
- **Day 5 (Week 2):** students build Project 3 and/or Project 4.

All solutions were tested and run without errors.
